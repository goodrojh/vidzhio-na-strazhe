# ВИДЖИО — посадочная страница

Продающий лендинг для **ВИДЖИО** — установка систем видеонаблюдения и безопасности
для загородных домов от 300 м² в Москве и Московской области.

## Стек
- React 18 + Vite 5
- Tailwind CSS 3
- Mobile-first, статический билд (GitHub Pages)

## Разработка
```bash
npm install
npm run dev      # локальная разработка
npm run build    # сборка в dist/
npm run preview  # предпросмотр статического билда
```

## Структура
- `src/App.jsx` — все секции лендинга
- `src/components/Logo.jsx` — логотип (SVG)
- `public/media/` — изображения и видео (Higgsfield: Nano Banana Pro + Kling 3.0)
- `assets/` — исходные сгенерированные медиа

## Деплой
Статический билд из `dist/` публикуется в ветку `gh-pages`.
